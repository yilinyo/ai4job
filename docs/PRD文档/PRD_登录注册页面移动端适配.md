# PRD：登录注册页面移动端适配

## 1. 背景

登录页与注册页已具备桌面与平板布局，但在手机窄屏中，品牌介绍、三项统计或步骤信息、较大卡片留白会拉长首屏。注册页验证码输入与发送按钮也会改为纵向排列，降低填写效率。

## 2. 目标

- 让用户在宽度不超过 520px 的手机上无需横向滚动即可完成登录或注册。
- 将认证表单、主按钮和登录/注册切换入口置于更高的信息优先级。
- 保留现有蓝白企业风格、品牌识别、表单字段、邮箱验证码与校验逻辑。

## 3. 范围

### 登录页

- 缩小手机端页面和表单卡片留白，并调整标题字号。
- 保留品牌标识、标题与简短说明。
- 隐藏三项统计信息，避免其在手机端纵向堆叠。
- 确保账号、密码、登录和注册链接始终在容器内可见、可点击。

### 注册页

- 缩小手机端页面和表单卡片留白，并调整标题字号。
- 保留品牌标识、标题与简短说明。
- 隐藏三项注册步骤信息，避免其挤占表单首屏空间。
- 验证码输入框与发送按钮在手机端保持同一行；倒计时与加载状态不能导致布局跳动、换行或溢出。

## 4. 非目标

- 不改变账号、密码、邮箱、验证码字段与校验规则。
- 不修改登录、注册、发送验证码接口或路由。
- 不重新设计桌面与平板端认证页面。

## 5. 验收标准

- 在 520px 及以下宽度，登录和注册页不存在横向滚动或内容裁切。
- 输入控件与主按钮保持适合触控的尺寸，登录/注册切换入口可操作。
- 手机端不显示登录统计块和注册步骤块，但品牌与当前操作标题保持清晰。
- 注册验证码输入和发送按钮保持同一行，倒计时、禁用与加载状态下布局稳定。
- 在桌面、平板与手机视口，既有登录、注册、邮箱验证码、校验与跳转流程不回归。
