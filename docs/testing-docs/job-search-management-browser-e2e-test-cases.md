## 用户画像与旅程拆解

| 用户画像 | 用户目标 | 起始状态 | 成功结果 |
| --- | --- | --- | --- |

## 失败与诊断

- TC-002 登录错误凭证：错误密码场景没有稳定停留在登录页并展示 `用户名或密码错误`。一次执行中仍进入后台，需优先排查前端 token/session 清理、接口返回处理，以及真实后端是否正确拒绝错误密码。

- TC-021 投递编辑保存：从投递详情进入编辑页，修改复盘/评分后保存返回 `参数错误` 和 `操作失败，请稍后重试`。疑似编辑接口参数、DTO 字段或前端提交 payload 与后端契约不一致。

- RISK-004：真实后端数据会持久化，新增/删除用例会影响后续测试和已有业务数据；正式执行前建议使用 `QA_` / 日期前缀造数，并在执行记录中写清清理状态。
- RISK-005：浏览器测试主要观察前端行为和真实后端响应结果；若失败发生在接口契约、数据库约束或认证中间件层，需要结合 Network 面板、后端日志和接口测试进一步定位。
- BLOCK-001：账号隔离、空闪卡、重复提问记录等用例需要可控的第二测试账号或可重置测试数据集。
- BLOCK-002：删除保护、删除题目等 destructive 操作本轮未在真实数据上确认执行，避免误删已有业务数据。
- BLOCK-003：Element UI 下拉项在 Chrome 自动化中出现不可见超时，导致“投递创建页选择已有岗位并回填字段”只能验证手动创建路径。
