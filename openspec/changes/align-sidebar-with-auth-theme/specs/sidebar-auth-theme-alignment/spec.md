## ADDED Requirements

### Requirement: 登录后侧边栏必须延续认证页蓝白视觉语言
系统 MUST 将登录后的左侧侧边栏调整为与登录页、注册页一致的蓝白视觉风格，避免认证前后出现明显割裂的深色模板侧栏。

#### Scenario: 用户登录后查看左侧侧边栏
- **WHEN** 用户进入任意带侧边栏的后台页面
- **THEN** 系统展示浅蓝白基底的侧边栏视觉
- **AND** 侧边栏文字、图标、边界和留白与当前登录 / 注册页的蓝白企业级风格保持一致

#### Scenario: 用户悬停侧边栏菜单
- **WHEN** 用户将鼠标悬停在侧边栏可点击菜单项上
- **THEN** 系统使用浅蓝或浅灰蓝 hover 态反馈
- **AND** hover 态不得回退为旧的深色模板悬停样式

#### Scenario: 用户查看当前激活菜单
- **WHEN** 当前页面对应的侧边栏菜单处于激活状态
- **THEN** 系统使用蓝色强调文本、强调图标，以及白底或浅蓝底的激活容器突出当前菜单
- **AND** 激活态在展开和折叠状态下都保持可识别

### Requirement: 侧边栏 Logo 区与菜单容器必须保持统一浅色基调
系统 MUST 调整侧边栏顶部 Logo 区与菜单容器的背景和边界处理，使其与菜单区形成同一套浅色蓝白视觉，而不是保留深灰独立色块。

#### Scenario: 用户查看展开态侧边栏顶部
- **WHEN** 侧边栏处于展开状态
- **THEN** Logo 区背景、标题文字和菜单容器风格保持统一
- **AND** 顶部不得出现与主体风格明显割裂的深色横条

#### Scenario: 用户折叠侧边栏
- **WHEN** 用户将侧边栏折叠
- **THEN** Logo 图标、菜单图标和激活态仍保持清晰可辨
- **AND** 折叠后的浅色背景与展开态保持同一视觉体系
