## MODIFIED Requirements

### Requirement: 岗位库一级导航必须使用统一且自然的菜单展示文案
系统 MUST 为岗位库一级导航入口提供与其它菜单一致的展示文案，不得暴露 `route.*` 原始 key 或保留与实际定位不一致的过渡性命名。

#### Scenario: 用户查看岗位仓库菜单
- **WHEN** 用户登录后查看左侧导航中的岗位库入口
- **THEN** 系统展示自然一致的岗位导航文案，例如“岗位仓库”或经确认的统一命名
- **AND** 菜单标题不得显示 `route.岗位仓库`、缺失 key 或其它原始国际化占位内容

### Requirement: 岗位库一级导航必须使用贴合岗位语义的图标
系统 MUST 为岗位库一级导航入口使用与岗位、职位机会或招聘语义贴合的图标，并与简历仓库入口形成统一的导航识别体系。

#### Scenario: 用户查看岗位仓库图标
- **WHEN** 用户查看左侧侧边栏中的岗位库入口
- **THEN** 系统展示与岗位语义贴合的图标
- **AND** 该图标与简历仓库、个人信息等业务入口保持统一的线面风格和强调色逻辑

### Requirement: 岗位库作为一级入口时必须遵循新的蓝白侧边栏样式
系统 MUST 在岗位库入口所在的一级导航层使用更新后的蓝白侧边栏样式，确保岗位库不会继续依赖旧的深色模板侧栏来显示激活态和 hover 态。

#### Scenario: 用户进入岗位列表页
- **WHEN** 用户从左侧导航进入岗位列表
- **THEN** 岗位库入口在蓝白侧边栏中正确显示当前激活态
- **AND** 激活态、hover 态和图标强调方式与简历仓库入口保持一致
