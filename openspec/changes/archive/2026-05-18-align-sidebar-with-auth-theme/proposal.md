## 为什么要做

当前登录页和注册页已经采用了统一的蓝白企业级认证页视觉语言，但用户登录进入系统后，左侧侧边栏仍保留模板默认的深色后台风格，导致“认证前”和“认证后”的产品观感割裂。与此同时，侧边栏菜单标题目前同时混用了国际化 key 和直接中文文案，部分业务菜单会暴露出 `route.简历仓库` 一类不一致展示，影响导航的专业度与可读性。

本次变更希望在不扩大到整站重构的前提下，先把左侧侧边栏统一到与登录 / 注册页一致的蓝白视觉特征，并同步收敛导航标题与图标表达，让简历与岗位相关入口的命名、层级感和识别性更统一。

## 变更内容

- 将系统左侧侧边栏从当前模板默认深色风格调整为与登录页、注册页一致的蓝白系视觉语言。
- 调整侧边栏的背景、文字、hover、激活态、分组层级和 Logo 区样式，使其与现有认证页的浅蓝渐变、白色卡片、蓝色强调色保持一致。
- 统一侧边栏业务菜单的标题配置方式，避免菜单直接展示 `route.*` key。
- 将“简历仓库”和“岗位仓库”入口文案调整为与其它导航一致的展示形式，不暴露国际化前缀。
- 为“简历仓库”和“岗位仓库”选择更贴合语义且风格一致的侧边栏图标。
- 保持现有导航层级不变，不在本次变更中重组一级 / 二级菜单结构。

## 能力定义

### 新增能力

- `sidebar-auth-theme-alignment`：登录后的左侧侧边栏采用与登录 / 注册页一致的蓝白视觉语言，并保持导航激活、悬停和折叠态下的可识别性。

### 修改能力

- `resume-navigation-structure`：简历相关导航标题需要使用统一的国际化 key 或统一展示文案，不得在侧边栏中暴露 `route.*` 原始 key。
- `job-posting-library-management`：岗位库作为一级导航入口时，需要使用统一的菜单展示文案与更贴合岗位语义的图标表达。
- `auth-page-enterprise-layout`：认证页建立的蓝白企业级视觉特征需要与登录后的基础导航框架形成连续体验，而不是只停留在未登录页面。

## 影响范围

- 影响前端样式变量：侧边栏颜色、文字色、激活态、hover 态和 Logo 区样式需要统一调整。
- 影响前端布局组件：`layout/components/Sidebar` 相关组件需要按新的视觉口径调整。
- 影响路由配置：简历仓库、岗位仓库等菜单标题与图标配置需要统一。
- 影响国际化文案：侧边栏业务菜单需要补齐或改用稳定的 `route` key，避免中文直写与 key 混用。
- 影响视觉验收：需要验证登录 / 注册页与登录后侧边栏在蓝白风格、留白和强调色上保持连续体验。

## 非目标

- 不在本次变更中重构顶部导航、标签页或内容区卡片视觉体系。
- 不在本次变更中调整简历管理、岗位库、面试题库等业务模块的导航层级关系。
- 不在本次变更中扩展新的业务页面或新增新的导航入口。
- 不要求本次变更同步重做整套品牌设计或主题切换能力。
