## 3. MCP 鉴权与工具服务

- [ ] 3.1 评估并接入支持 Streamable HTTP 的 Go MCP SDK，将协议依赖限制在 MCP interface adapter 中。
- [ ] 3.2 实现仅接受 `Authorization: Bearer ai4job-...` 的 API Key MCP 鉴权中间件，通过整串 Key 摘要定位有效记录，拒绝 Cookie、JWT 头、查询字符串凭据、无效、已撤销或已过期 Key，并将 `userID` 和 `apiKeyID` 注入请求上下文。
- [ ] 3.3 实现 MCP application adapter，使用上下文用户身份调用现有投递、面试进展、简历版本和题库服务，不调用 Gin handler，不接受客户端 `userId`。
- [ ] 3.4 实现 `get_resume_interviews`，在验证简历版本归属后返回关联投递、岗位快照、当前状态和面试进展，并支持文档约定的分页参数。
- [ ] 3.5 实现 `list_interview_workflows`，按当前用户范围返回全部投递记录的简历版本、岗位快照、当前状态和流程节点。
- [ ] 3.6 实现 `list_interview_questions`，复用既有题库筛选、分页和用户隔离规则。
- [ ] 3.7 在题库应用服务中实现单事务 `CreateQuestions` 批量创建能力，复用现有字段与枚举校验，限定一次 1-50 条并在任一条失败时整体回滚。
- [ ] 3.8 实现 `create_interview_questions`，将题目固定归属当前 API Key 用户并返回逐项创建结果或可定位的批量校验错误。
